# Архитектура сессии питомца и permissions

## 1. Питомец: CompactPetChat + карточка статуса

### Компоненты

| Компонент | Роль |
|---|---|
| `src/components/CompactPetChat.tsx` | Компактный раскрывающийся чат на главной: свёрнут — шапка с именем питомца и пользователя; развёрнут — сообщения, голосовой ввод, история |
| `src/utils/pet.ts` | `calculatePetStats()` — уровень, XP и настроение из реальных данных |
| `src/pages/Dashboard.tsx` | Сетка: карточка статуса питомца (уровень/настроение) + CompactPetChat |

### Имя питомца

- Задаётся при регистрации (шаг знакомства после создания аккаунта: имя пользователя + имя питомца)
- Меняется в Профиле
- Хранится в `localStorage['fp_pet_name']` через `SettingsContext`
- Используется: шапка чата, приветствие, карточка статуса

## 2. Уровни и настроение (геймификация)

`calculatePetStats(transactions, goals)` вычисляет из реальных данных:

- **XP** = 5 за каждую операцию + 20 за каждую цель + 2 за каждый процент накоплений по целям
- **Уровень** = `floor(xp / 50) + 1`; прогресс-бар показывает, сколько XP до следующего уровня
- **Настроение** зависит от активности за последние 7 дней:
  - нет операций — 40% («грустит»)
  - есть операции — 60% («спокоен»)
  - 3+ операций за неделю — +15%
  - расходы больше доходов — −20%; доходы есть — +10%
  - шкала: 80%+ «доволен», 55–79% «спокоен», ниже — «грустит»

Смысл: питомец «растёт» вместе с тем, насколько активно пользователь ведёт финансы — это мягкая мотивация заполнять операции и двигаться к целям.

## 3. Сессия питомца (PetSessionBanner)

| Аспект | Реализация |
|---|---|
| Когда создаётся | При открытии чата (CompactPetChat разворачивается) |
| Где хранится | `localStorage`, ключ `pet_session_data_{userId}` (гость: `pet_session_data_guest`) |
| Сколько живёт | 5 минут с момента создания |
| После закрытия приложения | Осталось меньше 5 минут — восстанавливается, иначе удаляется |
| Изоляция | Ключ по `userId` — у каждого пользователя своя сессия и своя история чата (`pet_chat_history_{userId}`) |

## 4. Permissions питомца (реализовано)

| Уровень | Действия | Реализация |
|---|---|---|
| **Может сам** | Отвечать на вопросы; читать агрегаты; объяснять интерфейс | Только чтение, данные через props |
| **Может предложить** | «Добавить расход 200 ₽ — Еда», «Создать цель…» | LLM возвращает JSON-действие → `extractAction()` отделяет его от текста → карточка в чате |
| **Только с подтверждением** | Создание операции; создание цели | Кнопки «Подтвердить/Отмена» на карточке; создание через те же `handleAdd`/`addGoal`, что и UI |
| **Запрещено** | Любые удаления; смена профиля; действия без подтверждения | Delete-колбэки в чат не передаются |

Инфраструктура: Edge Function `chat-proxy` (деплой: `supabase functions deploy chat-proxy --no-verify-jwt`), таблицы БД создаются `supabase/schema.sql`.

## 5. Онбординг

- `OnboardingModal`, показывается один раз после входа (`pet_onboarding_done`)
- Первый экран — приглашение: «Пройти обучение» / «Пропустить» (необязательный)
- 5 шагов: Операции → Статистика → Цели → Чат с питомцем → Готово
